# 双恋爱 / 跳过三人探戈 0.1.4 实验版

作者：Hexiao Zhang。工具与原创源码采用 BSD-3-Clause，分发时保留 LICENSE、NOTICE 和第三方声明。游戏资源的权利归原权利人。

本版保留双恋爱条件、绕过三人探戈陷阱，并调整结局及庄园双人常驻。Triss 使用独立躺椅与客房床位；0.1.4 将她的家具及对话位置移到 Yen 西北侧约 4.1 米处，避开旧位置花丛。

适用已核对的 Steam Remastered build 25773555，以及 Blood and Wine 资源。版本仍为实验版；23 项离线检查和 5 项配置审计通过，完整实机验收尚未完成。

保存并退出游戏后，在本目录运行：

```powershell
& .\Install-DualRomance.ps1 -GamePath 'C:\Games\The Witcher 3' -Action Install
```

将示例路径替换为自己的游戏目录。已有 0.1.3 使用 `-Action Update`；只核对文件使用 `-Action Verify`。自动更新会先备份已知旧版，发现未知修改则停止。

欢迎已结束时，重启游戏，读取当前存档，切换另一张地图后再返回白鸦庄园，让新位置和社区活动重新加载。不必重做欢迎。禁用模组不会还原已经发生的任务状态，请保留安装前存档。

创意工坊副本与手动副本不要重复安装。当前包是手动安装发行包，尚未验证 Workshop 上传和订阅加载。

未包含另行开发的房间演出原型。包内 SHA256SUMS.txt 用于核对文件，不能证明实际游戏行为正常。
