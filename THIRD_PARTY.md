# Format references and credits

- [WolvenKit-7](https://github.com/WolvenKit/WolvenKit-7): CR2W field/table layouts, CRCs, actor/entity buffers and animation format references. Referenced for format documentation; the application is not bundled or required at runtime.
- [Systemcluster/w3edit](https://github.com/Systemcluster/w3edit): bundle v5, metadata v7 and VLQ references. Its original BSD-2-Clause copyright and license are retained in `licenses/w3edit-BSD-2-Clause.txt`.
- [CD PROJEKT RED REDkit documentation](https://cdprojektred.atlassian.net/wiki/spaces/W3REDkit): quest conditions, mod layout and publishing workflow.

The builder uses the owner's installed game as its input. It preserves retail
path hashes and object identities, validates source fingerprints, and rebuilds
the modified containers without converting another game's resource version.
